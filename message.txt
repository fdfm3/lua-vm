SECTION 1: CORE CONCEPTS AND MENTAL MODEL
Matcha is an external LuaVM environment that exposes a subset of Roblox-like APIs. It is NOT a full Roblox engine, NOT an internal injector, and does NOT guarantee support for every Roblox API. It acts as a partial compatibility layer with documented deviations.
When generating or reviewing Matcha code, assume:
Only documented classes/methods/properties are safe to use.
Many standard Roblox patterns fail silently or behave differently.
Some functions exist but are incomplete stubs.
Contradictions in older docs are resolved canonically in this document.
SECTION 2: CANONICAL AI RULES (HIGH PRIORITY)
2.1 Instance Creation
Instance.new() is NOT supported.
Workaround: Clone existing instances in the hierarchy or manipulate existing objects.
2.2 HTTP Requests
Canonical Recommendation: Use global httpget(url, headers?) and httppost(url, body, contentType?, headers?).
Note: Even if DataModel:HttpGet / DataModel:HttpPost appear in class listings, treat the globals as the reliable path. Engine HTTP methods on game are not directly hooked.
2.3 Error Handling
error(...) in Matcha PRINTS a red console line; it does NOT raise a catchable Lua error.
To raise a catchable error, use: assert(false, message).
2.4 Loadstring / Load Behavior
Syntax errors still return a function.
The error is printed only when the returned function is called.
Top-level return values are DROPPED.
Do NOT rely on loadstring("return 5")().
If a chunk must output data, use globals or side effects.
2.5 Scheduler Functions
wait(time) returns nothing.
task.wait(time?) returns nothing.
task.spawn(fn) runs immediately and does NOT forward extra args.
task.defer(fn) is currently a NO-OP.
task.delay(time, fn) is currently a NO-OP.
2.6 Require Module Loading
Requires explicit extension: .lua or .luau.
Other extensions are rejected.
Resolves from Matcha module root, NOT from writefile/readfile workspace.
Do not assume a file confirmed by isfile() can be required.
2.7 Base64 Encoding
base64encode(data) stops processing at the first \0 null byte.
Do NOT use base64encode for arbitrary binary data containing null bytes.
2.8 Instance Equality
As of Aug 6, 2026: instanceA == instanceB is fully supported.
Manual .Address comparison is no longer required.
2.9 Attributes
GetAttribute() and SetAttribute() are supported (Fixed Aug 6, 2026).
2.10 Remote Events/Functions (Pro/Hybrid Mode)
RemoteEvent:FireServer(...) is supported.
RemoteFunction:InvokeServer(...) and RemoteFunction:InvokeFunction(...) are supported (Fixed Sep 11, 2026).
Treat availability as mode-dependent.
2.11 RunService.Stepped
Matcha passes ONLY deltaTime.
Standard Roblox passes (time, deltaTime). Adjust callbacks accordingly.

task.wait(time: number?)
Yields current thread for time seconds, or until next frame if omitted. Returns NOTHING.

SECTION 8: GARBAGE COLLECTOR MODDING
These functions find and modify values held in game's Lua garbage collector by name (weapon stats, config tables, etc.).
getgc(name: string): { table }
getgc(names: { string }): { table }
Returns every garbage-collected value stored under name(s). Result is array of entries. Each entry is table:
key: name found under
value: current value
type: value's type (number, string, boolean, table, function, userdata...)
addr: value's memory address
Same name can be stored in many places; multiple entries normal. Empty table if nothing found.
setgc(key: string, value: Any): int
setgc(values: { [string]: Any }): int
Sets every garbage-collected value stored under key to value, scanning collector on each call. Pass table to set multiple keys. Only values whose type matches value are changed. Returns number of values set. WARNING: Slow. Do not run inside loops.
applygc(cache: table, key: string, value: Any): int
applygc(cache: table, values: { [string]: Any }): int
Same as setgc, but applies to cache returned by getgc instead of scanning again. Call getgc once, reuse cache with applygc for repeated updates (loops/reset values). Refresh cache via getgc if values rebuilt (respawn/switch weapon). Returns number of values set. FAST PATH.
Recommended Pattern:
Scan once: local cache = getgc({ "FireRate", "MagAmmo" })
Apply repeatedly: applygc(cache, { FireRate = 0, MagAmmo = 999999 })
Refresh cache on major state changes.
NOTE ON INCONSISTENCY: Older examples may show getgc(true). This form is NOT part of canonical signature. Prefer getgc("Name") or getgc({ "Name1", "Name2" }).
SECTION 9: FILE SYSTEM
Paths relative to Matcha workspace folder (e.g., C:\matcha\workspace). / and \ interchangeable. Case-insensitive.
ALLOWED EXTENSIONS for readfile/writefile/appendfile:
.txt .lua .luau .json .cfg .dat .ini
Any other extension (images, audio, executables) raises "file extension not allowed". Contents are binary-safe; store raw/binary data under .dat.
writefile(path: string, content: string): nil
Creates path (or overwrites) with content. Missing parent folders created automatically. Content written exactly, including binary. Errors if disallowed extension or existing folder.
readfile(path: string): string
Returns contents of path as string (binary-safe). ERRORS if file does not exist. Guard with isfile or pcall.
appendfile(path: string, content: string): nil
Appends content to end of path, creating file if not exists. Content concatenated exactly (no separator inserted).
makefolder(path: string): nil
Creates folder at path, including missing parents. No-op if folder exists. Errors if file occupies path.
isfile(path: string): boolean
Returns true only if path is existing file; false for folders/missing. NEVER ERRORS.
isfolder(path: string): boolean
Returns true only if path is existing folder; false for files/missing. NEVER ERRORS.
listfiles(path: string): { string }
Returns immediate children of path (files/folders, NOT recursive) as workspace-relative paths sorted alphabetically. Entries passable to isfile/isfolder/readfile. listfiles("") lists root. Errors if path missing or is file.
delfile(path: string): boolean
Deletes file (or empty folder) at path. Returns true if removed, false if path did not exist. Errors if path is NON-EMPTY folder (use delfolder).
delfolder(path: string): boolean
Recursively deletes folder (or file) at path and everything inside. ALWAYS returns true, even if path did not exist.
SECTION 10: HTTP
httpget and httppost are SYNCHRONOUS. Block until response arrives. Return response body as string. NEVER RAISE ERROR: HTTP error status (e.g., 404) returns server response body; connection failure returns empty string.
httpget(url: string, headers: table?): string
Sends GET request to url. Optionally pass table of request headers.
httppost(url: string, body: string, contentType: string?, headers: table?): string
Sends POST request to url with body. contentType defaults to "application/json". Optionally pass table of request headers as fourth argument.
Canonical JSON Pattern:
local HttpService = game:GetService("HttpService")
local body = httpget("https://example.com/data.json")
if body ~= "" then
local ok, data = pcall(function()
return HttpService:JSONDecode(body)
end)
if ok then
-- use data
end
end

ipairs(t: table): (function, table, number)

Standard iteration. ipairs stops at first nil hole. NOTE: pairs does NOT honor Luau __iter metamethod; always iterates raw table.
select(n: number | "#", ...): ...
Standard, including negative indices. select(-1, ...) returns last argument.

Returns t[i] through t[j] (defaults i=1, j=#t). Exposed as global. Behaves identically to table.unpack.

Raises catchable error (Matcha:: , or assertion failed!) if value falsy. Otherwise returns arguments unchanged. WAY TO RAISE CATCHABLE ERROR IN MATCHA.

Standard. Returns true plus results on success, or false, "Matcha:: " on runtime fault.

SECTION 16: CODE EXAMPLE PATTERNS (NEUTRAL)
Pattern 1: Basic Drawing Loop
Use RunService.RenderStepped or Heartbeat to update Drawing objects. Always check visibility/onScreen if using WorldToScreen. Clean up drawings on stop/disconnect.
Pattern 2: Safe HTTP JSON Decode
Always wrap HttpService:JSONDecode in pcall. Handle empty string responses from httpget/httppost gracefully.
Pattern 3: GC Caching Strategy
Scan once with getgc. Store result. Use applygc in loops/event handlers. Re-scan with getgc only after significant game state changes (respawn, zone change).
Pattern 4: Delayed Execution
Since task.delay/task.defer are no-ops, use:
task.spawn(function()
wait(delaySeconds)
targetFunction()
end)
Pattern 5: Argument Passing to Threads
Since task.spawn doesn't forward args, use closures:
task.spawn(function()
myFunction(arg1, arg2)
end)
